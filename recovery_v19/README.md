# V19：异常恢复与明确提示

基于用户已确认可用的 V18。第五项优化：文件缺失、格式不支持、校验失败或读取超时时，有限重试、失败跳过，并保留可用画面。

## 现在怎么用

1. TF 卡沿用刚才正常播放的 V18 素材：PLAYLST.BIN、PIC000*.BMP、MUSIC0*.FPA。**本次无需重新转换或复制素材。**
2. 用 BitWriter 下载本目录的 `competition_recovery_v19.bit`，选择 PROGRAM_SRAM、5 MHz。
3. 屏幕顶部应显示 **FPGA V19**。正常时，图片、音乐、帘幕转场和 SW1～SW4 操作延续上一版。

TD 工程是 `competition_recovery_v19.al`。重新编译可使用 `build.ps1`。

仍使用 SRAM 配置；断电需要重新下载位流。Flash 固化是下一项。

## 发生错误后

| 情况 | 自动处理 |
|---|---|
| 某张图片不存在、BMP 头错误、尺寸或编码不支持、文件截断 | 首次失败后再试最多 2 次；仍失败就标记该图片，按切图方向寻找下一张可用图片 |
| 某首歌曲不存在、FPA 头与清单不一致、读取不完整或 CRC 不通过 | 最多再试 2 次；仍失败就跳过该歌曲，继续寻找可用歌曲 |
| 所有图片都失败 | 停止自动查找，保留已经显示的完整图片；没有成功图片时显示背景与原因。可用音乐仍允许播放 |
| 所有歌曲都失败 | 停止音乐查找并保持静音，图片仍可手动切换或自动轮播 |
| PLAYLST.BIN 缺失或不合法 | 最多再试 2 次，然后停止并提示；不猜测歌曲长度、地址或校验值 |

- 每次自动重试至少间隔约 **0.5 秒**，共享读卡器忙时会继续等待安全时机。
- 每个素材自动尝试最多 **3 次：初次 + 2 次重试**。坏素材在本次运行中被记住，后续自动轮播或预读会绕开它。
- 读卡无数据超时约 10 秒。完全无法读卡时，一轮排查可能较久，但不会无限循环自动尝试同一组坏文件。
- 新图完整写入并排空后才允许转场；失败时不把半张图切到前台。
- 歌曲只有通过读数对齐和全曲校验才允许播放。跳到不同长度的歌曲时，会重新计算预读空间，保护当前仍在播放的数据。
- 图片损坏不会修改 TF 卡上的文件；程序只读取素材。

## 屏幕提示怎么看

错误提示放在屏幕底部，使用现有英文字库。例如：

```text
MUSIC 2 MISSING     RETRY 1/2 K4
PIC 3   BAD HEADER  SKIPPED K4 RETRY
CATALOG MISSING     STOPPED K4 RETRY
```

| 提示 | 含义与处理 |
|---|---|
| CATALOG | 素材清单 PLAYLST.BIN |
| PIC n / MUSIC n | 第 n 张图片 / 第 n 首歌曲 |
| MISSING | 缺少文件，检查卡根目录及完整扩展名 |
| BAD HEADER | 文件头无效，或歌曲与清单不是同一个素材包 |
| CRC ERROR | 文件头或歌曲数据校验失败，重新复制同一个素材包 |
| READ TIMEOUT | 读卡长时间没有数据，检查卡的接触和文件系统 |
| BUFFER FULL | 缓冲区溢出，自动重试后仍出现则需继续排查读写链路 |
| SHORT FILE | 文件提前结束，可能复制不完整 |
| UNSUPPORTED | 图片尺寸/编码或清单容量超出当前支持范围 |
| MEM STALL | 内存写入未能按时结束，需要继续排查内存链路 |
| RETRY 1/2、2/2 | 正在安排第 1、2 次自动重试 |
| SKIPPED | 此素材已被跳过 |
| STOPPED | 该类素材已无可用项，或清单不可用，停止自动重试 |

普通提示显示约 4 秒，随后回到正常状态栏；停止状态持续显示。多个故障同时出现时依次以最新提示为主，停止状态会在临时提示结束后重新显示。

### KEY4 的重试作用

- **故障提示可见时**，KEY4 优先作为该类素材的重试/重新查找键，暂不增加音量。
- 图片：清除该类坏素材记录，恢复尝试；忙时按下的重试请求会等待到安全时机。
- 音乐：清除歌曲坏素材记录，恢复尝试；正在进行的读取或播放不会被强行中断。
- 清单：失败等待时重新开始一轮清单读取。
- 提示消失后，正常观看模式下 KEY4 恢复音量增加。
- 仍可用 KEY1 / KEY2 切换图片；加载期间保留最近一次切图请求。

本版不支持运行中热拔插 TF 卡。需要修复卡上文件时，开发板断电取卡、复制后安全弹出，装回并重新下载位流。重启也会清除本次运行的坏素材记录。

## 按键与开关

| 控件 | 功能 |
|---|---|
| SW1 | 下：手动切图；上：自动轮播 |
| SW2 | 下：静音；上：出声 |
| SW3 | 下：隐藏音频波形；上：显示 |
| SW4 | 下：正常观看；上：参数设置 |
| KEY1 / KEY2，观看模式 | 下一张 / 上一张 |
| KEY3 / KEY4，观看模式 | 音量减 / 加 5%；故障提示时 KEY4 优先重试 |
| KEY1 / KEY2，设置模式 | 当前参数加 / 减 |
| KEY3，设置模式 | 切换音量、亮度、对比度 |

初始音量仍为 10%。素材管理工具仍可使用 V18 工程内的 START_MEDIA_TOOL.cmd；本目录也保留同一套工具和素材格式。

## 备份与确认范围

- 相邻 `media_catalog_v18` 工程保持原样；本目录 `backup` 内有修改前完整备份。
- 回滚只需下载 V18 位流，素材格式兼容。
- BUILD_STATUS.json 记录实际编译结果、现有约束下时序、位流哈希和资源占用。
- 本次进行工程构建与交付文件完整性核对；没有添加或运行仿真/自动化测试，尚待上板确认异常恢复行为。
- 恢复逻辑针对可识别的文件和数据错误；持续供电、物理卡接口或 SDRAM 故障可能仍需重新上电排查，不能由跳过文件保证恢复。
