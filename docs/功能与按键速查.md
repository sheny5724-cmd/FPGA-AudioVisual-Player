# 声画视窗功能与按键速查

整理日期：2026年10月23日。主片使用 V19；V20 为单独下载的视频扩展工程。

## 开拍前

开发板断电约 5 秒再上电，确认顶部 V19。SW1 下、SW2 上、SW3 下、SW4 下；VOL 10%、BRT 0、CON 100%。先确认 TF 卡、HDMI A 及实际外放声音正常。

## V19 开关

| 开关 | 下 | 上 |
|---|---|---|
| SW1 | 手动切图 | 自动轮播 |
| SW2 | 静音 | 允许声音输出 |
| SW3 | 隐藏波形与峰值条 | 显示波形与峰值条 |
| SW4 | 观看模式，隐藏设置 | 设置模式，显示参数面板 |

## V19 按键

| 按键 | 观看模式 SW4 下 | 设置模式 SW4 上 |
|---|---|---|
| KEY1 | 下一张图片 | 当前参数增加 |
| KEY2 | 上一张图片 | 当前参数减少 |
| KEY3 | 音量减 5 个百分点 | 选择 音量 → 亮度 → 对比度 |
| KEY4 | 音量加 5 个百分点 | 正常情况下无操作 |

| 参数 | 范围 | 单次步进 | 上电默认 |
|---|---|---|---|
| VOL 音量 | 0～100% | 5 个百分点 | 10% |
| BRT 亮度 | −64～+64 | 16 | 0 |
| CON 对比度 | 50～150% | 25 个百分点 | 100% |

- SW4 每次打开默认选择音量；KEY3 循环选择 VOL、BRT、CON。调参前 SW1 拨下。
- 每次短按后松开。长按不连发；切换模式先释放按键。
- 有故障提示时 KEY4 优先重试；静音不暂停，隐藏波形不静音。
- V19 歌曲按清单自动循环，没有手动上一首或下一首映射。
- 参数在本次切图换歌中保留，重新上电恢复默认；TF 卡更新需断电取卡。

## V20 操作差异

- 临时加载 video_v20/competition_video_v20.bit，只用 JTAG / SRAM Download；保持 Flash 为 V19。
- TF 卡需有 VIDEO01.FPV 与 VIDEO02.FPV，原 V19 素材保留。
- 屏幕显示 FPGA V20 VID；观看模式 KEY1/KEY2 为下一段/上一段，从头播放。
- SW1 上：播完自动换下一段循环；SW1 下：播完保持末帧。
- SW2 静音、SW3 波形、SW4 设置，以及 KEY3/KEY4 音量操作沿用 V19。没有暂停或进度拖动。
- 断电重启回 V19。拍摄画面注明“V20 独立视频扩展版 需单独加载”。

## 讲解时说准确

- HDMI 输出 640×480，约 59.52 Hz。V20 视频素材 160×90、15 fps、逐帧 256 色，放大至 640×360 居中。
- FPGA 直接读 BMP/FPA/FPV；JPG、PNG、MP3、MP4 是电脑素材转换工具的输入。
- V19/V20 音源为 24 kHz μ-law 单声道，送 HDMI 时为 48 kHz；不是原生无损立体声。
- 实际显示为最近邻缩放、帘幕揭示和时域波形；不要说双线性、交叉淡化或 FFT 频谱。
- 运行计时不是联网时钟，字幕目前不是任意可编辑中文。
- V21 双声道人声异常仍未解决；异常恢复全场景与长时间连续运行尚未完整验收。
